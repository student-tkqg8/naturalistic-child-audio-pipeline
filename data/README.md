# Data

The audio recordings and original annotation data used in this project are not included in this repository because they contain sensitive participant data and cannot be publicly redistributed.

The repository instead includes `example_model_input.csv`, which contains synthetic example data illustrating the format expected by the analysis and inference scripts. All identifiers and file paths in this example are fictional.

The original study data consisted of 30-second clips with clip-level annotations including speech presence, speech type, languages present, and other annotation variables. Development and evaluation split information was also stored alongside the annotations.
